# 部署检查清单

## 发布前

- [ ] 已使用明确的 Git tag 或 commit 构建发布版本
- [ ] 已确认 `.env`、SQLite、Chroma 数据和缓存未进入镜像
- [ ] 已吊销并轮换历史上提交过的 API Key
- [ ] 生产密钥通过受限环境文件或 Secret 管理系统注入
- [ ] `backend/.env` 权限仅允许部署用户读取
- [ ] `docker compose config` 校验通过且未输出意外配置
- [ ] 自动化测试全部通过
- [ ] 已确认 Python、依赖和镜像版本
- [ ] 已备份现有 SQLite 和 Chroma 数据
- [ ] 已在非生产环境验证备份恢复及向量索引重建

## 主机与网络

- [ ] 服务器 CPU、内存和磁盘满足要求
- [ ] 首次运行可下载嵌入模型，或已准备离线缓存
- [ ] 仅对公网开放 HTTPS 入口
- [ ] Uvicorn、SQLite、Chroma 和 Docker daemon 未直接暴露公网
- [ ] 已配置 TLS、域名、防火墙和安全响应头
- [ ] 已配置请求体大小、访问频率和连接超时限制
- [ ] 已为登录、注册和 Memory API 配置网关限流
- [ ] `/api/memory/rebuild` 已限制调用频率
- [ ] `CORS_ALLOWED_ORIGINS` 只包含正式前端域名

## 数据

- [ ] 已确认 `backend/init_db.py` 只执行结构初始化/迁移
- [ ] 旧单用户数据已备份，legacy 数据归属方案已确认
- [ ] Docker `memory_data` volume 已创建并正确挂载
- [ ] 已设定备份频率、保留周期、异地副本和负责人
- [ ] 已记录恢复命令及最近一次恢复演练时间
- [ ] 已配置磁盘空间告警
- [ ] 确认当前仅运行一个后端实例和一个 Uvicorn worker

## 上线验证

- [ ] `docker compose ps` 显示服务正常
- [ ] `/health` 返回 HTTP 200
- [ ] 页面可通过正式 HTTPS 域名打开
- [ ] 可以保存一条非敏感测试记忆
- [ ] 可以通过关键词和语义问题召回该记忆
- [ ] 可以删除测试记忆
- [ ] 后端和 Nginx 日志没有密钥、异常堆栈或持续错误
- [ ] LLM 调用延迟与费用处于预期范围

## 运维交接

- [ ] 已交付镜像版本、启动/停止/回滚命令
- [ ] 已交付密钥轮换流程，但未在文档中记录真实密钥
- [ ] 已交付备份、恢复和 Chroma 重建步骤
- [ ] 已配置日志轮转、监控和告警联系人
- [ ] 已说明当前支持用户隔离，但仍不支持水平扩容
- [ ] 已安排 API Key、依赖和基础镜像的定期更新
