# 实施计划

1. **初始化项目**：建立目录、依赖清单、环境变量模板与 Docker Compose 本地运行配置。
2. **搭建后端基础**：创建 FastAPI 应用、健康检查、配置加载，以及 SQLite 和 ChromaDB 的初始化。
3. **实现记忆存储**：提供存储 API，将原始内容写入 SQLite，并将对应文本及元数据写入 ChromaDB。
4. **实现记忆查询**：提供查询 API，执行 ChromaDB 语义检索并回查 SQLite 原始记忆。
5. **接入智能体回答**：通过 OpenAI 兼容 API 将问题和检索记忆交给 LLM，返回整合回答与记忆来源。
6. **完成前端与验证**：实现纯 HTML/JS 单页交互，补充错误处理和使用说明，并验证端到端流程可运行。
